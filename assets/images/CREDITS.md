## Brand assets

`logo.jpeg` is the supplied master logo. The flame / helix mark was cut out of
it and rebuilt as transparent WebP files; the baked-in transparency checkerboard
was removed by deriving alpha from pixel saturation.

| File | Use |
| --- | --- |
| `logo-mark.webp` | Full-colour mark, light backgrounds |
| `logo-mark-cream.webp` | Flat cream silhouette, dark surfaces (footer, dark theme) |
| `../favicon.webp` | 64 × 64 favicon, bone tile (`favicon.png` is the fallback) |
| `../apple-touch-icon.webp` | 180 × 180 home-screen icon |
| `../logo-tile.webp` | 512 × 512 tile for social / structured data |

The wordmark is live text (Newsreader + IBM Plex Mono), not raster.
